# Reverse Breakout — Survive the Balls

A browser arcade survival game inspired by Breakout — but reversed.
Avoid bouncing balls and survive as long as possible.

---

## Features

- Survival-based gameplay
- Increasing difficulty
- HP system
- Timer & High Score tracking
- Power-ups
- Sound effects & music
- Lightweight & fast
- Fully browser-based

---

---

## How to Run

1. Download or clone repository
2. Open `index.html` in a browser

---

## Controls

Mouse / Arrow Keys — Move paddle  
Start — Begin game  
Mute — Toggle sound  

---

## Game Mechanics

- Start with 100 HP
- Balls bounce and deal damage
- Survive as long as possible
- Difficulty increases over time
